# 业务规则引擎

## 配置与语义

在“权限与授权”的业务规则表单使用“保存业务规则”按钮。管理员选择已安装、具有法人/医院/组织维度的真实单据、动作、组织、有效期和 Block/Warn。身份字段不可改，修订必须带当前 revision。规则中的组织、有效期与 source 的真实业务日期匹配；医院范围、上级组织和精确组织的规则累积执行，priority 数值大者先执行，不覆盖下级规则。

`when_json` 可为空，表示总是适用。`assertion_json` 必填。适用条件为假是 Skipped；约束不通过得到 Blocked 或 Warned。没有适用约束返回 allowed=false，不能把跳过当作批准。试算仅提供当前校验结果，不授予业务权限。

示例：对 HRP Master Data Request 的 submit 动作，只允许更新申请。

```json
{"field":"operation","op":"eq","value":"Update"}
```

金额不能超过同一单据限额，且必须有非空、正数量明细：

```json
{"all":[
  {"field":"amount","op":"lte","other_field":"limit_amount"},
  {"table":"items","quantifier":"all","where":{"field":"qty","op":"gt","value":0}}
]}
```

字段必须来自当前根单据，明细内只能访问本行字段，禁止跨层路径。all/any 组合非空；明细 all 和 any 都要求至少一行。支持 required、empty、eq、ne、gt/gte/lt/lte、in/not_in、length_lte。缺失字段不会通过不等于或排除集合判断。金额按源货币单位比较，不隐式换算。日期为 ISO 格式，Datetime 按 Frappe 站点时区约定，不接受带偏移量常量。

## 接入与权限

第一条真实链路是主数据申请提交：原有角色、归属、组织、修订和提案检查继续生效；有适用策略则阻止 Blocked/Unconfigured，Warned 可提交并留存证据。无任何匹配策略时保留原流程。后续财务等要求强制策略的模块应调用 enforce_business_rules(required=True)，不能只读取试算或日志判断是否获准。

规则所用字段的类型、Select 选项、权限级别及遮罩状态冻结为契约，元数据变化会拒绝执行，需要管理员正常修订后继续。用户同时需要源 DocPerm、数据范围、所有引用字段的读取权限及遮罩权限；权限不足不会返回真假结果供推断。

“业务规则验证”页面支持实时试算及留存。留存请求必须带试算时的 source_modified 和 decision_digest；源、策略、主体等变化则冲突，需重新试算。重放同一写入键只返回历史记录 ID；当前业务必须重新校验。记录只追加，不允许通用 API 修改、删除、改名或取消。

日志不存金额、明细原文或条件的实际观察值，只存摘要、字段名和规则结果。普通用户通过范围日志接口逐条核验当前源及字段权限；通用列表仅系统超级用户开放。源已删除、字段权限撤销或引用无效时拒绝读取。正常源删除还受 Frappe 关联记录保护。

## 事务、边界与运维

源写操作和规则配置分别使用医院共享锁与排他锁，防止校验中途改变规则；主数据提交的证据与源提交同事务。拒绝动作回滚其数据库记录，脱敏事件保留在运行审计中；需落库的拒绝证据由显式 record 操作创建。数据库锁/快照冲突由外层请求或工作任务完整回滚重试，HTTP 508 使用相同幂等键重试。

规则选择使用共享锁读取完整当前行，再直接构造只读策略对象。医院锁本身不会刷新 MariaDB 已有的事务快照，不能在取得锁后重新用普通快照查询加载规则。回归同时覆盖“业务先持锁，配置等待”和“业务先建立旧快照，配置已提交”两个顺序，后者必须应用新修订。

上限：每棵条件树 64 节点、深度 5，每组最多 16 条件，每集合最多 32 值，64 条适用规则，128 个不同字段引用，每明细最多 2000 行，每次试算 100000 节点操作。超过上限明确拒绝，不截取部分规则后返回通过。规则 JSON 16 KiB，字段契约 32 KiB；数值必须有限，绝对值小于 10^24、最多 12 位小数。日志列表每页最多 50，扫描偏移上限 10000；大量历史记录检索需通过源引用或后续审计报表规划，不能据此声称完成医院容量验收。

没有实际医院策略种子，也不扫描历史业务单据。部署前备份隔离站点，重复迁移后核对业务数据及其他站点基线。回滚先暂停本项目队列/调度，再回退代码并保留规则和历史表；不删除证据、清空幂等表或直接重写台账。医院范围、真实接口、容量及 UAT 资料仍待补齐。
