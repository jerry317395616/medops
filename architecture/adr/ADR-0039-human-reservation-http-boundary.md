# ADR-0039 人工预占操作的受控 HTTP 边界

## 背景与问题

ADR-0037 的阶段边界禁止新增公开 API；后续已完成默认关闭的私有释放事务、完整历史和隔离已提交数据竞争验证。继续建设人工操作流程需要正式扩展 HTTP 边界。确认、续期和财务过账分属不同事务，客户端必须明确识别各自结果与重试语义。

## 决策驱动因素

复用既有领域服务和 Frappe 标准事务；限定当前人类网页会话；保持证据不可变、精确金额、组织范围、逐阶段撤权检查、加密幂等和凭证隐私。服务器维护期间只在本地及一次性 GitHub CI 站点验证。

## 备选方案

1. 放开标准 DocType 保存或直接调用数据库：绕过已审查写入协议，拒绝。
2. 在接口中重写财务算法或自动延长决定：产生第二套权威和隐式授权，拒绝。
3. 新增默认关闭的人工会话 HTTP 适配层，复用全部既有领域服务：采用。

## 决策

本决策只替代 ADR-0037 的阶段性 API 禁令及已落后的实施状态；其不可变根、独立完整证据、唯一后继、精确金额、五分钟会话凭证、完整历史和回滚约束全部保留。原文只更改 Superseded 状态与后继引用，不重写已接受内容。

新增严格布尔 `medops_reservation_operations_enabled` 总开关，缺失、假值、数字或字符串都关闭。新接口只允许经过原生认证的 POST 网页会话及现有预算管理角色；拒绝访客、Authorization 令牌请求、后台调用、未知参数和未经明确确认的财务命令。各领域服务的默认关闭私有开关继续独立生效，确认接口的既有开关不变。不得在部署时自动开启或新增角色、用户范围、分享、DocType 标准写权限。

适配层提供首次预占、原决定续期、续期后首次预占、释放预览、释放过账和完整当前位置读取。命令通过既有严格请求构造器、已审查领域服务和审计/加密幂等执行；只在清洁请求中建立 READ COMMITTED 最外层事务，Frappe 在请求结束提交或回滚。适配层和领域服务不提交，不在持锁事务内访问外部系统。读取也复核当前角色、来源、字段和组织权限；已提交根仍只代表首笔事实，不能用其旧余额显示当前状态。

所有携带凭证的新方法在现有最前置隐私钩子登记，覆盖 cmd、v1/v2 RPC 路径及兼容后缀，在认证和分发故障前屏蔽原生诊断视图；私有载体保留真实业务解析。读取只返回选定来源事实、公开预算键和经过完整历史核验的位置，不暴露会话/凭证摘要或私有意图 JSON。预览返回凭证只供当前页面内存确认，不能进入日志、通用序列化、URL 或持久浏览器存储。

后续原生页面须展示来源、预算、精确金额、理由、有效期与操作影响；使用未勾选的明确确认，编辑输入即失效，丢弃过期异步响应。未知网络结果保留同一命令及幂等键供原样重试；不能自动换键再过账。过账失败不得把确认成功显示成财务成功，续期不得自动发生。本决策不声称页面、真实人员验收或生产开放已经完成。

## 后果

增加可被调用但默认拒绝的 HTTP 适配面，必须承担原生认证前故障的隐私回归。标准证据权限继续关闭；管理角色还需满足原生来源、字段和组织范围权限，接口不自行授予权限。其他预算写入口的协作协议、医院规则和负载验收仍是生产前置条件。

## 验证与退出条件

本地质量和治理检查；原生 POST/GET/访客/令牌/后台/严格开关与明确确认拒绝；所有新凭证方法在实际原生 Error Log 与 SDK 序列化故障中保持隐私。真实财务 HTTP 探针只能附加在精确命名且有严格标记、位于 GitHub RUNNER_TEMP 的一次性新站点，使用原生会话、来源、预算和标准控制器，检查持久结果、重复回执、续期及原决定拒绝、释放决定后失败的完整 HTTP 回滚、历史重放和换会话拒绝。不得在普通站点留下合成不可变财务事实。

这些用例即使通过也不等于真实人员操作、所有写入口或医院容量证明。所有生产开关保持关闭，直到界面、权限矩阵、医院接口、数据迁移及上线验收另有完整证据。

## 迁移与回滚

本次新增接口不新增表、列、索引或角色，依赖先前的27字段释放证据表及索引。维护期间不连接服务器或迁移。关闭总开关和相关私有入口后可撤销适配层；保留全部已经提交的根、事件、确认证据及幂等回执和兼容的完整读取器，禁止删除合法释放事实或退回不理解释放历史的读取代码。

## 安全与合规

只允许明确授权的人类会话动作，AI 不得自动确认或过账。沿用全部原始和续期独立证据验证，凭证不授予数据权限。全部 Frappe 生态来源继续使用用户 GitHub fork，不访问官方源码仓库、不修改上游。生产启用、真实医院验收及服务器维护结束均不能由本决策或 CI 结果推定。
