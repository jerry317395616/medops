# MedOps 上线验收与持续开发范围

## 目标与范围

项目所有者于 2026-10-25 要求继续完成 HRP 功能开发，达到上线可用。
开发范围沿用 36 个模块、设计目录、工作流及 `backlog/backlog.csv` 的完整规划。
不因某个模块通过测试而缩小总体目标；范围裁剪须由项目所有者明确确认。

当前按大型三甲、单医院多院区推进。目标医院、用户规模、现有系统与脱敏联调资料
暂未提供。以下医院专项验收保留为待验证项，不阻止通用功能开发，也不以模拟结果
替代医院验收。

## 开发与验证顺序

1. 完成权限审批基础，包括职责分离、时限升级、业务规则与核心工作台。
2. 按依赖推进预算及费用、资金、会计桥接与成本，复用 ERPNext 标准控制器。
3. 完成采购、供应商、合同、物资与资产等流程，形成预算到支付与对账闭环。
4. 完成人事绩效、运营治理、数据集成及门户等既定范围。
5. 对完整发布候选执行业务验收、容量与恢复演练；逐项补齐医院专项证据。

各阶段均交付模型、服务、权限、接口、操作入口、异常路径、迁移、测试及文档。
发现跨模块缺陷时修正根因，禁止通过删除断言、放宽安全策略、改写台账或虚构验收
证据推进状态。测试数据使用合成数据；当前开发站不承载真实患者数据。
