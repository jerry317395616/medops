## 模型、服务、权限与迁移

新增的 DocType 是 `HRP Foundation` 的内部技术数据，不属于 398 个业务设计 DocType。
它不加入 Workspace、Fixture 或全局搜索。标准 Frappe migrate 会同步其表结构，不需要
patch。发布前必须备份数据库和 Site 加密密钥。

模块启停写入从 API 层迁到
`medops.hrp_foundation.services.module_settings.SetModuleEnabledService`，对外只暴露
`medops.hrp_foundation.services.set_module_enabled`。API 不再直接保存 DocType。

## 破坏性变更

`PLT-009` 现在要求 `Idempotency-Key`。缺失或非法键返回 `IONE-CORE-0003`，相同键与
不同请求返回 `IONE-CORE-0007`。调用方必须先升级再发布服务端。
