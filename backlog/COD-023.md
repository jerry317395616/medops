# COD-023 实现统一编号服务

## 任务信息

- 阶段：1-核心闭环
- 模块：HRP核心平台 / HRP Foundation
- 优先级：P0
- 前置任务：COD-022
- 风险：关键业务基础设施、并发、幂等、数据不可变和权限

## 验收映射

| 验收项 | 实现 | 自动化证据 |
| --- | --- | --- |
| 统一编号方案 | `HRP Numbering Scheme`、受控模板契约、乐观修订服务 | 纯契约和 Frappe 元数据/修订测试 |
| 原子发号 | `tabSeries` 原子递增、事务行锁、全局编号唯一约束 | 连续分配、维度/月份隔离和碰撞回滚测试 |

| 迁移与工作区 | 幂等索引迁移、HRP 首页中文入口 | 重复迁移、索引和默认工作区映射测试 |

## 实现范围

- 新增统一编号纯契约、方案与预留 DocType、领域服务、权限、API 和迁移；
- 替换设计目录中的通用编号方案占位模型；
- 新增不可变编号预留模型；
- 更正 CORE-006 的历史 `medops_core` 路径并补充方案维护和预留查询 API；
- HRP 首页新增“编号方案”和“编号预留”，保留组织、主数据和系统配置入口；
- 不修改 Frappe、ERPNext、Frappe HR，不连接或变更 Press 生产站点。

## 非目标

- 不为各业务 DocType 自动接线；后续业务任务按需调用 CORE-006；
- 不实现 COD-024 的统一数据权限解析器；当前采用角色和预留所有者边界；
- 不回收已发编号，不保证无空洞连续；
- 不允许自定义代码、SQL、正则或表达式模板。
