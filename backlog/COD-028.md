# COD-028 SLA 与超时升级

状态：In Progress。前置任务为 COD-027；本任务的完整交付尚未完成。

## 实现范围

- 受控 SLA 策略：目标单据与组织范围、起算字段、响应和处理时限、暂停及完成状态、工作日历和有序升级步骤。
- 复用 ERPNext 的工作时间计算及标准日历、Frappe 待办和通知；不修改这些应用的产品源码。
- ERPNext 的完整 SLA 控制器要求非提交类单据及 `status` 字段。HRP 申请有独立状态和提交生命周期，因此复用其日历计算能力，通过 HRP 适配器接入，避免改写原有工作流。
- 跟踪真实业务单据的计时周期、暂停、恢复、完成及逐级升级，防止重复调度重复派单。
- 策略写入、人工处置具备权限、组织范围、幂等、乐观修订与脱敏审计；升级不自动批准、付款或记账。
- 对策略、日历与组织引用进行验证，支持真实 HTTP 权限与异常路径测试、重复迁移、工作台入口和运行手册。

## 验收要求

时限、工作日与节假日、暂停恢复、跨组织拒绝、并发重复执行、策略修订、角色或日历失效、通知受众权限、错误重试和完成后停止升级均需有证据。正常路径通过不代替异常及恢复测试。
