# COD-027 实现不相容职责校验

## 任务信息

- 阶段：1-核心闭环
- 模块：HRP核心平台 / HRP Workflow Authorization
- 优先级：P0
- 前置任务：COD-026
- 风险：职责冲突漏检、规则漏配、组织上下文伪造、敏感身份泄露和生产迁移

## 验收映射

| 验收项 | 实现 | 自动化证据 |
| --- | --- | --- |
| 职责规则模型 | `HRP Segregation Rule` 声明动作、责任人字段、冲突角色和组织范围 | 元数据、蓝图、目录和字段白名单测试 |
| 默认拒绝校验 | 全部适用规则聚合；冲突或漏配均拒绝 | 纯决策与真实单据集成测试 |
| 最小权限 | 调用方读权限、被校验用户 DocPerm 和组织范围同时成立 | 用户、角色、范围和 Guest 测试 |
| 受控 API | `CORE-003` 每次实时只读决策；`CORE-032` 幂等写规则；`CORE-033` 只读查询 | HTTP、实时不重放、写入幂等、乐观锁和只读测试 |
| 审计与隐私 | 只记录 DocType、动作、数量和摘要；摘要绑定全部已评估规则名/修订/策略摘要 | 响应及日志身份脱敏、全量策略摘要测试 |
| 迁移与入口 | 两个复合索引和中文权限工作区 | 重复迁移与 Workspace 映射测试 |
