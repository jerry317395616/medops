## 实现边界

本任务不创建 DocType、Fixture、Patch 或 Workspace。站点内不启动压测，也不接受结果
写入；场景只允许 `medops` 的 GET 路径。初始基线不实现尚未交付的预算、库存、三单
匹配、故障注入和安全场景，只建立它们后续必须复用的执行契约。

## 验证

```bash
python -m unittest tests.test_performance_baseline -v
python scripts/performance_baseline.py \
  --base-url http://127.0.0.1:8200 \
  --profile smoke \
  --dry-run
python scripts/change_manager.py validate
python scripts/change_manager.py check \
  --base-ref origin/main \
  --task COD-015 \
  --correlation-id COD-015-local
```

锁定 Bench 集成测试必须覆盖系统角色、危险环境、配置异常、重复读取无写入、脱敏审计以及
`PLT-018` 的真实 HTTP 成功和访客拒绝。实际容量测试只在隔离的生产等价 test 环境运行，
不得连接 Press 生产 Site。
