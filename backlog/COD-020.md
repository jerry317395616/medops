## 实现边界

只修改 `medops` 的 `HRP Master Data` 模块及公共契约。五类标准主数据仅被读取和链接，
批准不修改 ERPNext 标准记录。不创建第二个 App，不修改三个锁定上游，不连接生产 Press。

## 验证

```bash
python -m unittest tests.test_master_data -v
python scripts/change_manager.py validate
python scripts/change_manager.py check \
  --base-ref origin/main \
  --task COD-020 \
  --correlation-id COD-020-local
python scripts/quality.py
```

锁定 Bench 必须运行新增主数据集成测试和全量回归，随后重复迁移，并验证 development、
test、demo 三个隔离站点 `Error Log` 为零。

## 迁移与回滚

新增三个表、目标类型唯一约束和待审查询索引，不创建或修改 ERPNext 标准记录。升级前备份
数据库；回滚应用提交并 migrate，保留表和数据，不执行破坏性删除。
