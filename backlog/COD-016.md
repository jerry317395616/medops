## 实现边界

不创建 DocType、Fixture、Patch、Workspace 或第二个自研 App。Frappe Site 只能
读取治理契约，不能启动扫描、生成 SBOM、上传原始报告或写入扫描结果。

扫描不连接 Press、生产数据库或外部业务系统。原始发现只存在于临时 CI 工作区。

## 验证

```bash
python -m unittest tests.test_software_supply_chain -v
python scripts/security_supply_chain.py plan
python scripts/change_manager.py validate
python scripts/change_manager.py check \
  --base-ref origin/main \
  --task COD-016 \
  --correlation-id COD-016-local

```

真实安全流水线还必须使用固定工具运行 `security_supply_chain.py run`，通过
CycloneDX 1.7 校验和全部零容忍门禁。锁定 Bench 集成测试必须覆盖角色、异常、
无写入、脱敏审计和 `PLT-019` HTTP 成功/访客拒绝。

## 迁移与回滚

无数据库迁移。回滚应用提交和 CI 配置即可。`.artifacts/security` 与 CI 制品不进入
Site 数据库，删除制品不影响业务数据。
