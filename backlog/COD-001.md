# COD-001 建立 mono-repo 与分支保护

## 设计依据

- `AGENTS.md`
- `architecture/single_app_architecture.md`
- `architecture/repository_governance.md`
- `.github/branch-protection.json`

## 交付

- 唯一自研 App 和 Python 包统一为 `medops`。
- 36 个 Module 继续位于 `medops` 内，注册表、`modules.txt` 与目录对应。
- 根目录初始化为 Git mono-repo，并以 `main` 作为默认分支。
- 仓库根目录符合 Press App Source 结构，可直接发现 `pyproject.toml` 和 `medops/hooks.py`。
- GitHub 使用强制 PR、线性历史和讨论解决保护 `main`，禁止管理员直推、强推和删除。
- 当前单维护者阶段保留 `CODEOWNERS`，但不设置无法满足的独立批准门槛。
- `scripts/repository_contract.py` 阻止多 App、旧前缀、上游源码混入和直接写受保护台账。
- 仓库级单元测试验证上述契约；持续集成流水线留待 COD-005。

## 任务适用面

本任务不创建业务 DocType、服务、写 API、Workspace、Fixture 或数据库迁移。
权限、业务审计和业务幂等不适用；仓库治理的异常路径由自动化测试覆盖。
